# Minecraft Mod: Livro de Afiação 250

Este mod Fabric para Minecraft 1.20.1 adiciona um livro de uso único que encanta uma espada com Afiação 250. O livro pode ser encontrado na aba Combate do inventário criativo ou obtido por comando.

## Install

1. Instale o Minecraft Java Edition 1.20.1 com o Fabric Loader 0.15.0 ou mais recente.
2. Instale o Fabric API para Minecraft 1.20.1.
3. Coloque o arquivo JAR do mod na pasta `mods` do Minecraft.
4. Inicie o jogo com o perfil Fabric.

## Use

1. Segure o Livro de Afiação 250 na mão principal.
2. Segure uma espada na mão secundária.
3. Clique com o botão direito para aplicar Afiação 250 à espada. O livro é consumido, exceto no modo Criativo.
4. Para obter o livro por comando, use `/give @s sharpness250book:sharpness_250_book`.
